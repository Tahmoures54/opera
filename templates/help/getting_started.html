Getting started with OPERA

Set up your project workspace in a few steps

  1. Sign in and secure your account
    Sign in with your organization account and configure two-factor authentication.
  2. Create a project
    Enter the project code, name, client, contractor and schedule.
  3. Define the project structure
    Create systems and subsystems with unique codes.
  4. Assign project members
    In project operations, assign organization members as commissioning, QC, client, operations or viewer participants.
  5. Execute check sheets and manage punch items
    Create and issue check sheets, record results, complete independent QC verification and track punch items through final acceptance.
  6. Certification and handover
    Follow the approved sequence: MC (Mechanical Completion) → RFC (Ready for Commissioning) → RFSU (Ready for Start-Up) → Operations Acceptance. In the current OPERA build, the RFC certificate is stored internally as type RF; a separate RF / Ready-for-Start-Up certificate is not implemented.
