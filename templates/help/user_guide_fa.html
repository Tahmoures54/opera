OPERA User Guide

Commissioning and start-up workflow reference

1. Project setup

Create a project, define systems and subsystems, and assign project members using OPERA roles. Membership is tenant-scoped and does not alter the inherited account role.

2. Check sheets

Create a pre-commissioning, commissioning or functional-test sheet. Add inspection items and acceptance criteria, issue the sheet, then record actual results. OK/N/A items require independent QC verification. Contractor and client sign-off must be performed by different authenticated users.

3. Punch List

Raise A/B/C/D punch items, assign them to active project members, set target dates and move them through controlled status transitions. Verification and waiver require the appropriate project permission and leave an immutable history.

4. Witness and Hold Points

Schedule a point against a check sheet and optional item, record notification, attendance, result and release. Required witness items cannot be signed off until released.

5. MC, RF, RFSU and handover

MC certification is blocked until all subsystem check sheets are signed and category A/B punch items are cleared. Continue through RF certification and RFSU, then record operations acceptance or rejection.

6. Progress evidence

Progress snapshots capture signed-off check-sheet ratios, weighted completion and open/closed punch counts. Audit events, signatures and revisions provide traceability.

Electronic sign-off in this release is an authenticated acknowledgement, not a qualified cryptographic signature.
